# Cyber Explorers

An English, mobile-friendly learning adventure for ages 10–14.

Six original missions: Packet Post, Sharing Space, Message Detective, Shield Studio, Robot Rules, and The Missing Poster. Includes interactive illustrations, hints, practice and local browser progress. No account, analytics, advertising or leaderboard.

This independent derivative preserves the Git history of [cyber-study-ru](https://github.com/johnny-fridburg/cyber-study-ru). GitHub does not support a native fork of a repository into the same personal owner account; this is a separate public repository with shared history, rather than a GitHub-labelled fork.

It adapts selected foundations for children; it does not reproduce the adult syllabus or offensive-security labs. All scenarios are fictional. Referenced educational resources are Google Be Internet Awesome and NCMEC NetSmartzKids; no endorsement is implied.

Open `index.html` directly or serve the folder. Progress is stored in the current browser and can be exported/imported as JSON. Do not write personal information in the detective notebook. GitHub Pages hosting may process ordinary request information.

Live: https://johnny-fridburg.github.io/cyber-explorers-kids/

## Updating

Edit the standalone `index.html`. Push to main; GitHub Pages serves the repository root.
