Detailed Curriculum Roadmap & Study Guide
Module 1: Foundations of Cybersecurity
Duration: 5 Academic Hours
Module Description: Introduces course goals, structure, and operational fields. Focuses on the information security ecosystem, recognized standards, regulations, popular threats, and the offensive attack model.
Key Curriculum Topics
Course Overview & Scope: Alignment of goals, expectations, and security domains.
Threats & Attack Vectors: Current popular threats and vectors targeting modern environments.
The Cyber Kill Chain: Understanding the structured steps of an offensive cyber operation.
Security Frameworks & Regulations: Key industry security standards and regulatory compliance requirements.
Essential Study Takeaways
Core Theoretical Concepts: Memorize the stages of the Cyber Kill Chain model to evaluate how adversaries target organizations.
Practical & Regulatory Context: Recognize how security frameworks govern organizational posture and compliance requirements.
Module 2: Networking Fundamentals
Duration: 50 Academic Hours
Module Description: Provides foundational knowledge of software, network architectures, communication infrastructure, IP services, and network access. Emphasizes security, network monitoring, automation, and packet analysis.
Key Curriculum Topics
Understanding Networks & Architectural Models: Deep dive into the OSI 7-layer model and TCP/IP model.
Networking Hardware: Hardware functionality of Switches, Routers, and Wireless Access Points (APs).
Addressing & Routing: IP Addressing, Subnetting, and Routing & Switching Basics.
Network Protocols & Communication: TCP, UDP, HTTP, DNS, and ICMP protocols.
Network Security & Monitoring: Basic network security, troubleshooting, and traffic analysis.
Practical Tools & Key Execution Areas
Wireshark: In-depth traffic capture, packet analysis, protocol breakdown, and troubleshooting.
Essential Study Takeaways
Protocol Distinctions: Understand stateful vs. stateless protocols (TCP vs. UDP) and domain resolution mechanisms (DNS).
Traffic Inspection: Master packet-level analysis and filtering techniques using Wireshark.
Module 3: Windows OS and Active Directory
Duration: 50 Academic Hours
Module Description: Covers operating system mechanics, server deployment, virtualization, system administration, and directory structures. Equips defenders with skills to manage environments and detect underlying threats, including cloud integration.
Key Curriculum Topics
Windows Architecture & Core Functionalities: System mechanics, process execution, and core architecture.
Virtualization & Management: Virtualization technologies, server installation, and Windows System Management.
Networking, Security, & Services: Windows service control, system processes, and network security policies.
Active Directory (AD) Infrastructure: AD Basics, Objects Management, Group Policies (GPO), and Access Control.
Automation & Cloud: PowerShell scripting basics and Cloud/Hybrid integration overviews.
Practical Tools & Key Execution Areas
PowerShell: Command-line administration, automation, and management.
Active Directory Administrative Center / GPO Management: Managing domain objects, rights, and policies.
Essential Study Takeaways
Active Directory Governance: Practice configuring Group Policy Objects (GPOs) to enforce security controls and manage access control lists across domain objects.
System Visibility: Understand Windows core services and processes to identify baseline behavioral anomalies.
Module 4: Linux Fundamentals for Cyber Security
Duration: 50 Academic Hours
Module Description: Teaches core Linux administration and operation. Since many security tools and cloud hosts run on Linux, this module emphasizes file permissions, command-line output handling, and system automation.
Key Curriculum Topics
Linux Overview & Architecture: Linux distributions, system architecture, and cybersecurity use cases.
Deployment: Linux installation methods and virtualization environment setups.
File System & Access Control: Directory structures, absolute/relative paths, and permission structures.
Administration & Operations: User & Group management, Process & System monitoring, and Linux networking.
Practical Tools & Key Execution Areas
Command Line Interface (CLI): Text streams manipulation, output redirection, file parsing, and process control.
Essential Study Takeaways
Permission Management: Master Linux permission structures (read, write, execute across user, group, and others).
Output Processing: Practice filtering and piping command outputs for system auditing and automated security tasks.
Module 5: Python Fundamentals
Duration: 50 Academic Hours
Module Description: Introduces Python—the primary programming language for cyber automation, security tool development, and workflow enhancement. Focuses on core computational logic and practical security libraries.
Key Curriculum Topics
Computational Logic: Problem-solving strategies, computational thinking, data types, and variables.
Environment Configuration: Setting up Integrated Development Environments (IDEs), interpreters, and compilers.
Program Flow: Control structures (conditionals, loops), functions, and modular programming.
Data Management & Resiliency: File operations, structured data handling, error handling, and debugging.
Extensibility: Integrating external libraries and working with Application Programming Interfaces (APIs).
Essential Study Takeaways
Automation Capabilities: Develop modular scripts to process raw system files, parse network output, and interact with web APIs.
Code Reliability: Implement structured error handling to ensure robust script execution during operational tasks.
Module 6: Introduction to AI: Practical Applications for Everyday Use
Duration: 15 Academic Hours
Module Description: Explores foundational Artificial Intelligence and Generative AI (GenAI) techniques to optimize daily productivity and streamline information security tasks.
Key Curriculum Topics
GenAI Fundamentals: Concepts, architecture basics, and cyber-specific use cases.
Tooling & Hands-on Application: Overview of AI platforms and practical execution.
Prompt Engineering: Designing targeted prompts for accurate output generation.
Document Processing & Repurposing: Personal and work document handling, content repurposing, and contextual automation.
Essential Study Takeaways
Prompt Optimization: Formulate clear prompts to automate administrative, documentation, and operational cyber workflows.
Practical AI Integration: Apply GenAI tools responsibly to synthesize data and accelerate routine analyses.
Module 7: Ethical Hacking – Infrastructure Attacks
Duration: 70 Academic Hours
Module Description: Focuses on Red Team methodology for local network infrastructures. Covers penetration testing workflows, vulnerability assessment, initial access, privilege escalation, and post-exploitation.
Key Curriculum Topics
Attack Methodology: Phased attack flow and Penetration Testing frameworks.
Reconnaissance & Mapping: Passive information gathering, DNS enumeration, network scanning, and port mapping.
Exploitation & Access: Password attacks, payload creation, payload execution, and vulnerability exploitation.
Advanced Red Teaming: Privilege Escalation techniques and Post-Exploitation activities.
Practical Tools & Key Execution Areas
Kali Linux: Primary offensive operating system platform.
Metasploit Framework: Exploit execution, payload development, and post-exploitation control.
Essential Study Takeaways
Reconnaissance to Exploitation: Map the complete path from passive DNS/port enumeration to active Metasploit execution.
Privilege Escalation: Focus on identifying system misconfigurations to escalate privileges post-compromise.
Module 8: Ethical Hacking – Application-Level Attacks
Duration: 40 Academic Hours
Module Description: Addresses vulnerabilities in web and cloud applications—the primary entry point for modern corporate breaches. Emphasizes web application assessment using BurpSuite and the OWASP methodology.
Key Curriculum Topics
Web Architecture: Web application components, protocols, and standard structures.
Industry Standards: The OWASP (Open Web Application Security Project) Standard and Top 10 framework.
Application Reconnaissance: Web application enumeration and form analysis.
Exploitation Techniques:
Cross-Site Scripting (XSS)
SQL Injection (SQLi)
Directory Traversal & File Inclusion (LFI/RFI)
Authentication Attacks & Form Brute-forcing
Practical Tools & Key Execution Areas
BurpSuite: Intercepting proxy configuration, HTTP traffic modification, request repeating, and automated attacks.
Essential Study Takeaways
Traffic Interception: Master routing HTTP/HTTPS traffic through BurpSuite to analyze and alter client-server interactions.
Vulnerability Analysis: Understand input-validation flaws, including SQL Injection mechanisms and XSS script injections.
Module 9: Ethical Hacking Project
Duration: 10 Academic Hours
Module Description: A hands-on practical project where students execute end-to-end infrastructure and application attacks, synthesizing Red Team concepts learned across previous modules.
Practical Objectives
Execute real-world penetration testing workflows against targeted networks and applications.
Perform recon, identify vulnerabilities, execute exploits, and report on security gaps.
Module 10: SOC Analyst Operations
Duration: 80 Academic Hours
Module Description: Prepares students for defensive Security Operations Center (SOC) roles. Covers infrastructure defense, traffic filtering, host behavioral analysis, malware inspection, and SIEM incident response.
Key Curriculum Topics
SOC Operations: Roles, responsibilities, and operational workflows in a SOC center.
Perimeter & Network Defense: Firewalls, IDS/IPS operational mechanics, traffic filtering, and firewall policy management.
Host & Behavioral Analysis:
Basic Static Analysis techniques.
Behavioral Analysis & Sandboxing routines.
System process monitoring and Indicators of Compromise (IOC) discovery.
Windows Registry analysis and Autoruns persistence checking.
SIEM Operations: SIEM architecture fundamentals, centralized logging, incident analysis, and triage workflows.
Practical Tools & Key Execution Areas
Splunk: Log aggregation, correlation search execution, dashboard navigation, and SIEM-driven incident response.
Process Monitor (Procmon): Real-time monitoring of file system, Registry, and process activity.
Autoruns: Detection of persistence locations in Windows registry and boot structures.
Essential Study Takeaways
Incident Detection: Use Procmon and Autoruns to identify host-based anomalies, malicious processes, and persistence keys.
SIEM Investigation: Construct search queries and correlate log events inside Splunk to trace attack scopes.
Module 11: Cyber Defense - Forensics
Duration: 40 Academic Hours
Module Description: Focuses on digital forensics and incident response (DFIR). Teaches techniques to extract, analyze, and construct artifact evidence following security incidents to determine adversary actions and prevent recurrences.
Key Curriculum Topics
Network Forensics & Threat Hunting: Analyzing network captures for evidence extraction and threat activity.
Storage & File System Forensics: Windows disk inspection, NTFS file system artifacts analysis, and Master File Table (MFT) extraction.
Timeline Analysis: Constructing MFT timelines and building the comprehensive "Super Timeline".
Volatile Memory Analysis: Performing RAM acquisitions and analyzing volatile memory artifacts.
Practical Tools & Key Execution Areas
Volatility Framework: Extraction and analysis of RAM images, active network connections, process trees, and injected code.
MFT Timeline Tools: Reconstructing file system events chronologically.
Essential Study Takeaways
Timeline Reconstruction: Analyze NTFS MFT data to generate precise chronological event logs of attacker activity.
Memory Forensics: Utilize Volatility command modules to inspect unencrypted memory artifacts, hidden processes, and volatile connections.
Module 12: Blue Team Project
Duration: 10 Academic Hours
Module Description: A hands-on defensive capstone project where students apply SIEM monitoring, threat hunting, log correlation, forensic timeline creation, and incident response procedures against simulated compromise scenarios.
Practical Objectives
Identify attack indicators, collect forensic evidence, trace threat actors using SIEM logs, and construct comprehensive incident response reports.
Module 13: Securing Industrial Control Systems (ICS) & OT Networks
Duration: 30 Academic Hours
Module Description: Addresses operational technology (OT) and SCADA/ICS environments in critical infrastructure. Details unique OT characteristics, risk management, sector-specific threats, and real-time operational response principles.
Key Curriculum Topics
ICS & OT Architecture: Introduction to Industrial Control Systems, SCADA, and operational environments.
Threat Landscapes: Historical and current threats, attacks, vectors, and security breaches in ICS networks.
Critical Infrastructure Security: Unique requirements, safety parameters, and constraints of OT operational environments.
Incident Management: Real-time incident response strategies and threat mitigation in live ICS environments.
Essential Study Takeaways
IT vs. OT Security Differences: Distinguish operational requirements between standard IT networks and high-availability, safety-critical OT/ICS environments.
ICS Threat Response: Analyze documented historical ICS attacks to build containment strategies for operational networks.
